# Supplied design provenance

Six readable HTML templates were extracted from the supplied Material QEMU export: Main, Onboarding, Overview, Machines, NewMachine and Console. They preserve reference source rather than executable application delivery or runtime evidence. Their asset identifiers refer to the original export; fonts and scripts are not bundled into the production runtime.

Original export SHA-256: `f71bef6f4949d059cc5a4e1c06e11b775a50cb599e1ba1723eccc497c5bd17a2`.

The original byte-for-byte export remains retained outside this public repository. Its encoded manifest triggered the publication-language scanner, so that encoded body was not published. Whether the match was incidental was not established; no broad exemption was added.

The earlier 56-board design corpus remains unchanged under `design/project` and `design/frames`. Its source and frames remain the complete existing reference package.
